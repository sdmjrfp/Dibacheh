# Dibacheh

[English](README.md) · [فارسی](README.fa.md) · [简体中文](README.zh.md) · [Español](README.es.md) · [العربية](README.ar.md) · [हिन्दी](README.hi.md) · [Português](README.pt.md) · [Français](README.fr.md) · [Русский](README.ru.md) · [Bahasa Indonesia](README.id.md) · [Deutsch](README.de.md) · [Türkçe](README.tr.md) · [日本語](README.ja.md)

Dibacheh はオフラインの学習計画アプリです。レッスンをセッションに分け、ライトナー方式で復習を予定し、変更のたびに計画全体を組み直します。データはお使いのコンピューターにだけ保存されます。

## 機能

- 日、週、月、または最後の復習までの全体表示。縦表示と横表示
- 「+」メニュー:レッスン、ルーチン、単発タスク、プロジェクト、独自の種類、既製のテンプレート
- 間隔を調整できるライトナー復習。レッスンごとに復習なしも可能
- 週と月のスコア付きレポート
- スマホでオフラインで読める HTML 書き出し
- 毎日のバックアップ。OneDrive、Google Drive、Dropbox、iCloud のフォルダにもコピー
- 1台のコンピューターで複数ユーザー。データは別々で、写真や既製の画像、任意のパスワードを設定可能
- 13 言語、イラン暦と西暦、ライトとダーク、50% から 200% の画面サイズ

## ダウンロード

**[最新版をダウンロード](https://github.com/sdmjrfp/Dibacheh/releases/latest)**。Python などのインストールは不要です。

| システム | ファイル |
|---|---|
| Apple チップの Mac | `…-AppleSilicon.dmg` |
| Intel Mac | `…-Intel.dmg` |
| Windows 10 と 11 | `…-Windows-Setup.exe` |
| Linux (x86_64) | `…-Linux-x86_64.AppImage` |

有料の署名がないため、初回はシステムが警告します。Mac:システム設定、プライバシーとセキュリティ、このまま開く。Windows:詳細情報、実行。

アプリがインターネットに接続するのは、バックグラウンドで新しいバージョンを確認するときだけです。設定でオフにでき、データは送信されません。

このファイルとアプリの翻訳は AI が作成したもので、人による確認は行われていません。
