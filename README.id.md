# Dibacheh

[English](README.md) · [فارسی](README.fa.md) · [简体中文](README.zh.md) · [Español](README.es.md) · [العربية](README.ar.md) · [हिन्दी](README.hi.md) · [Português](README.pt.md) · [Français](README.fr.md) · [Русский](README.ru.md) · [Bahasa Indonesia](README.id.md) · [Deutsch](README.de.md) · [Türkçe](README.tr.md) · [日本語](README.ja.md)

Dibacheh adalah perencana belajar luring. Aplikasi ini membagi tiap pelajaran menjadi sesi, menjadwalkan ulasan dengan metode Leitner, dan menyusun ulang seluruh rencana setiap ada perubahan. Data Anda tetap di komputer Anda.

## Fitur

- Rencana per hari, minggu, bulan, atau seluruhnya sampai ulasan terakhir, vertikal atau horizontal
- Menu "+": pelajaran, rutinitas, tugas sekali, proyek, jenis sendiri, dan templat siap pakai
- Ulasan Leitner dengan jeda yang bisa diatur, atau tanpa ulasan untuk satu pelajaran
- Laporan dengan nilai mingguan dan bulanan
- Ekspor HTML untuk dibaca luring di ponsel
- Cadangan harian, juga disalin ke folder OneDrive, Google Drive, Dropbox, atau iCloud
- Beberapa pengguna di satu komputer, dengan data terpisah, foto atau gambar siap pakai, dan kata sandi opsional
- 13 bahasa, kalender Hijriah Syamsiah dan Masehi, mode terang dan gelap, ukuran 50% sampai 200%

## Unduh

**[Unduh versi terbaru](https://github.com/sdmjrfp/Dibacheh/releases/latest)**. Tidak perlu memasang Python atau apa pun.

| Sistem | Berkas |
|---|---|

| Mac Intel | `…-Intel.dmg` |
| Windows 10 dan 11 | `…-Windows-Setup.exe` |

Aplikasi tidak memiliki tanda tangan berbayar, jadi sistem memberi peringatan pertama kali. Di Mac: System Settings, Privacy & Security, Open Anyway. Di Windows: More info, Run anyway.

Aplikasi hanya terhubung untuk memeriksa versi baru di latar belakang. Ini bisa dimatikan di Pengaturan dan tidak ada data Anda yang dikirim.

Berkas ini dan terjemahan aplikasi ditulis oleh AI dan belum ditinjau manusia.
