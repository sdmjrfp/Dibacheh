Dibacheh 是一款离线学习计划工具。把每门课程分成若干学习节,用莱特纳方法安排复习,每次更改后整个计划都会自动重新排列。您的数据只保存在自己的电脑上。

## 功能

- 按天、周、月或一直到最后一次复习查看计划,可纵向或横向
- “+”菜单:课程、例行任务、一次性任务、项目、自定义类型和现成模板
- 可调间隔的莱特纳复习,也可以删除某门课程的全部复习
- 报告,含每周和每月评分
- 导出 HTML,在手机上离线阅读
- 每日备份,并可复制到 OneDrive、Google Drive、Dropbox 或 iCloud 文件夹
- 13 种语言、伊朗太阳历和公历、浅色和深色模式、50% 到 200% 的界面大小
