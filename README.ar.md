# Dibacheh

[English](README.md) · [فارسی](README.fa.md) · [简体中文](README.zh.md) · [Español](README.es.md) · [العربية](README.ar.md) · [हिन्दी](README.hi.md) · [Português](README.pt.md) · [Français](README.fr.md) · [Русский](README.ru.md) · [Bahasa Indonesia](README.id.md) · [Deutsch](README.de.md) · [Türkçe](README.tr.md) · [日本語](README.ja.md)

دیباچه برنامج لتخطيط الدراسة يعمل دون إنترنت. يقسّم كل درس إلى جلسات، ويجدول المراجعات بطريقة لايتنر، ويعيد ترتيب الخطة كلها بعد كل تغيير. تبقى بياناتك على حاسوبك.

## المزايا

- الخطة باليوم أو الأسبوع أو الشهر أو كاملة حتى آخر مراجعة، عموديًا أو أفقيًا
- قائمة «+»: درس، مهمة روتينية، مهمة لمرة واحدة، مشروع، أنواعك الخاصة وقوالب جاهزة
- مراجعات لايتنر بفواصل قابلة للتعديل، أو دون مراجعة لدرس معين
- تقارير مع درجة أسبوعية وشهرية
- تصدير HTML للقراءة دون إنترنت على الهاتف
- نسخة احتياطية يومية، تُنسخ أيضًا إلى مجلد OneDrive أو Google Drive أو Dropbox أو iCloud
- 13 لغة، التقويم الهجري الشمسي والميلادي، الوضع الفاتح والداكن، حجم من 50٪ إلى 200٪

## التنزيل

**[تنزيل أحدث إصدار](https://github.com/sdmjrfp/Dibacheh/releases/latest)**. لا حاجة إلى تثبيت Python أو أي شيء آخر.

| النظام | الملف |
|---|---|
| Mac بشريحة Apple | `…-AppleSilicon.dmg` |
| Mac بمعالج Intel | `…-Intel.dmg` |
| Windows 10 و11 | `…-Windows-Setup.exe` |
| Linux (x86_64) | `…-Linux-x86_64.AppImage` |

البرنامج بلا توقيع مدفوع، لذا يحذّرك النظام في المرة الأولى. في Mac: إعدادات النظام، الخصوصية والأمان، الفتح على أي حال. في Windows: مزيد من المعلومات، التشغيل على أي حال.

يتصل البرنامج بالإنترنت فقط للتحقق في الخلفية من وجود إصدار جديد. يمكن إيقاف ذلك من الإعدادات، ولا تُرسل أي بيانات عنك.

كُتب هذا الملف وترجمات البرنامج بالذكاء الاصطناعي ولم يراجعها إنسان.
