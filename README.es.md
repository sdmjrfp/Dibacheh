# Dibacheh

[English](README.md) · [فارسی](README.fa.md) · [简体中文](README.zh.md) · [Español](README.es.md) · [العربية](README.ar.md) · [हिन्दी](README.hi.md) · [Português](README.pt.md) · [Français](README.fr.md) · [Русский](README.ru.md) · [Bahasa Indonesia](README.id.md) · [Deutsch](README.de.md) · [Türkçe](README.tr.md) · [日本語](README.ja.md)

Dibacheh es un planificador de estudio sin conexión. Divide cada lección en sesiones, programa los repasos con el método Leitner y reorganiza todo el plan tras cada cambio. Tus datos se quedan en tu ordenador.

## Funciones

- Plan por día, semana, mes o completo hasta el último repaso, vertical u horizontal
- Menú «+»: lección, rutina, tarea única, proyecto, tipos propios y plantillas listas
- Repasos de Leitner con intervalos ajustables, o ninguno para una lección
- Informes con nota semanal y mensual
- Exportación HTML para leer sin conexión en el móvil
- Copia diaria, también en tu carpeta de OneDrive, Google Drive, Dropbox o iCloud
- 13 idiomas, calendario solar hégira y gregoriano, modo claro y oscuro, tamaños del 50 % al 200 %

## Descarga

**[Descargar la última versión](https://github.com/sdmjrfp/Dibacheh/releases/latest)**. No hace falta instalar Python ni nada más.

| Sistema | Archivo |
|---|---|
| Mac con chip Apple | `…-AppleSilicon.dmg` |
| Mac con Intel | `…-Intel.dmg` |
| Windows 10 y 11 | `…-Windows-Setup.exe` |
| Linux (x86_64) | `…-Linux-x86_64.AppImage` |

La aplicación no tiene firma de pago, así que el sistema avisa la primera vez. En Mac: Ajustes del Sistema, Privacidad y seguridad, Abrir igualmente. En Windows: Más información, Ejecutar de todas formas.

La aplicación solo se conecta para comprobar en segundo plano si hay una versión nueva. Se puede desactivar en Ajustes y no envía ningún dato tuyo.
