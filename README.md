# دیباچه

سیستم آفلاین مدیریت یادگیری: برنامهٔ روزانه، پیگیری پیشرفت و مرور به روش لایتنر.
مشخصات کامل در [PROJECT_SPEC.md](PROJECT_SPEC.md) است.

## نصب (فقط یک بار، با اینترنت)

در Terminal داخل پوشهٔ پروژه:

```bash
python3 -m venv .venv
```

```bash
.venv/bin/pip install -r requirements.txt
```

پوشهٔ `.venv` یک محیط پایتون جدا برای همین پروژه است تا کتابخانه‌ها با بقیهٔ Mac قاطی نشوند.

## اجرا

روی `start.command` دوبار کلیک کنید. یا در Terminal:

```bash
.venv/bin/python app.py
```

بعد در مرورگر به `http://127.0.0.1:5000` بروید.

## اجرای تست‌ها

```bash
.venv/bin/python -m pytest
```

## ساختار پوشه‌ها

| فایل یا پوشه | کار |
|---|---|
| `app.py` | سرور و مسیرها |
| `scheduler.py` | موتور چینش برنامه، بدون وابستگی به Flask یا SQLite |
| `leitner.py` | قانون‌های جعبه و مرور |
| `database.py` | کار با SQLite |
| `sources.py` | خواندن منابع، Browse و باز کردن فایل |
| `exporter.py` | ساخت خروجی HTML |
| `templates/` | صفحه‌ها |
| `static/` | CSS و JavaScript |
| `static/vendor/` | کتابخانه‌های محلی (بدون CDN) |
| `tests/` | تست‌ها |
| `data/` | دیتابیس و backup؛ وارد Git نمی‌شود |
