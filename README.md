# دیباچه

سیستم آفلاین مدیریت یادگیری: برنامهٔ روزانه، پیگیری پیشرفت و مرور به روش لایتنر.
کد روی [GitHub](https://github.com/sdmjrfp/Dibacheh) و [GitLab](https://gitlab.com/sdmjrfp/Dibacheh) است. مشخصات کامل در [PROJECT_SPEC.md](PROJECT_SPEC.md) است. راهنمای ادامهٔ توسعه (برای برنامه‌نویس یا مدل هوش مصنوعی بعدی) در [AGENTS.md](AGENTS.md) است.

## دانلود و نصب

**[دانلود آخرین نسخه](https://github.com/sdmjrfp/Dibacheh/releases/latest)**. نصب Python یا چیز دیگری لازم نیست.

| سیستم | فایل | نصب |
|---|---|---|
| Mac با تراشهٔ Apple (M1 به بعد) | `…-AppleSilicon.dmg` | برنامه را به Applications بکشید |
| Mac اینتل | `…-Intel.dmg` | برنامه را به Applications بکشید |
| ویندوز ۱۰ و ۱۱ (۶۴ بیتی) | `…-Windows-Setup.exe` | اجرا کنید؛ دسترسی مدیر لازم نیست. `…-Windows-Portable.zip` نسخهٔ بدون نصب است |
| لینوکس (x86_64) | `…-Linux-x86_64.AppImage` | قابل اجرا کنید (`chmod +x`) و اجرا کنید. اگر اجرا نشد، `…-Linux-x86_64.tar.gz` را باز کنید و فایل `Dibacheh` را اجرا کنید |

**هشدار بار اول:** برنامه امضای پولی ندارد، پس سیستم بار اول هشدار می‌دهد.

- **Mac:** System Settings، بخش Privacy & Security، پایین صفحه Open Anyway.
- **ویندوز:** در پنجرهٔ SmartScreen روی More info و بعد Run anyway بزنید.

**بستن برنامه:** برنامه در مرورگر باز می‌شود. روی Mac از Dock با Quit، و روی ویندوز و لینوکس با دکمهٔ «⏻ بستن برنامه» بالای صفحه بسته می‌شود. بستن تب مرورگر برنامه را نمی‌بندد.

**لینوکس:** برای پنجرهٔ Browse باید `zenity` یا `kdialog` نصب باشد.

**داده‌ها** فقط روی کامپیوتر شما می‌مانند و هیچ چیزی به اینترنت فرستاده نمی‌شود. با نصب نسخهٔ تازه هم سر جایشان هستند:

- Mac: `~/Library/Application Support/Dibacheh`
- ویندوز: `%APPDATA%\Dibacheh`
- لینوکس: `~/.local/share/dibacheh`

استفادهٔ شخصی از برنامه رایگان است؛ جزئیات در [LICENSE](LICENSE). مجوز فونت‌ها و کتابخانه‌ها در [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) است.

## اجرا از سورس (فقط یک بار نصب، با اینترنت)

در Terminal داخل پوشهٔ پروژه:

به Python 3.11 یا تازه‌تر نیاز دارید.

```bash
python3 -m venv .venv
```

```bash
.venv/bin/pip install -r requirements.txt
```

پوشهٔ `.venv` یک محیط پایتون جدا برای همین پروژه است تا کتابخانه‌ها با بقیهٔ Mac قاطی نشوند.

## اجرا

**راه پیشنهادی: `Dibacheh.app`.** یک بار در Terminal این را اجرا کنید تا برنامه با آیکون ساخته شود:

```bash
zsh tools/build_app.sh
```

بعد `Dibacheh.app` را به Dock بکشید. با کلیک روی آن، برنامه بدون پنجرهٔ Terminal باز می‌شود. کلیک دوباره صفحه را باز می‌کند و Quit از Dock برنامه را می‌بندد. خود `Dibacheh.app` باید داخل پوشهٔ پروژه بماند. اگر macOS بار اول اجازه نداد، روی آن کلیک راست کنید و Open را بزنید.

**راه دیگر:** روی `start.command` دوبار کلیک کنید. یک پنجرهٔ Terminal باز می‌شود، برنامه اجرا می‌شود، و مرورگر پیش‌فرض Mac صفحهٔ برنامه را باز می‌کند. برای بستن برنامه، همان پنجرهٔ Terminal را ببندید.

- اگر برنامه از قبل باز باشد، `start.command` فقط مرورگر را باز می‌کند.
- اگر macOS بار اول اجازهٔ باز کردن `start.command` را نداد: روی آن کلیک راست کنید و Open را بزنید.
- اگر پیغام «برنامهٔ دیگری پورت 5000 را گرفته» آمد، معمولاً AirPlay Receiver است. آن را در System Settings خاموش کنید.

یا در Terminal:

```bash
.venv/bin/python app.py
```

بعد در مرورگر به `http://127.0.0.1:5000` بروید.

**آفلاین:** بعد از نصب، برنامه هیچ درخواستی به اینترنت نمی‌فرستد. همهٔ فونت‌ها و کدها داخل پروژه‌اند. فقط باز کردن لینک یوتیوب و فرستادن خروجی به تلگرام اینترنت لازم دارد.

**امتحان کردن بدون دست زدن به داده‌های اصلی:** برنامه را با یک دیتابیس جدا و روی پورت دیگری اجرا کنید (تا با نسخهٔ اصلی که باز است تداخل نکند)، و به `http://127.0.0.1:5001` بروید:

```bash
DIBACHEH_DB=/tmp/dibacheh-demo.sqlite3 DIBACHEH_PORT=5001 .venv/bin/python app.py
```

## استفاده: منابع درسی

- **والت Obsidian:** بالای صفحه روی «والت» کلیک کنید (یا از تنظیمات) و پوشهٔ والت را انتخاب کنید. فایل‌های داخل والت با Obsidian باز می‌شوند و بقیه با برنامهٔ پیش‌فرض Mac.
- **جست‌وجو:** کادر بالای فهرست در نام درس‌ها، بخش جلسه‌ها، یادداشت‌ها و آدرس منبع می‌گردد.
- **چند درس با هم:** دکمهٔ «+ چند درس». هر خط یک درس: عنوان، تعداد جلسه، زمان جلسه.
- **الگو:** در پنجرهٔ درس جدید، «ذخیره به‌عنوان الگو» تنظیمات فعلی را نگه می‌دارد و کادر «از روی الگو…» آن را دوباره پر می‌کند. الگوها از تنظیمات حذف می‌شوند.
- **جلسه از روی فایل:** اگر نوت عنوان داشته باشد یا PDF فهرست مطالب، بعد از Browse می‌شود هر عنوان یا فصل را یک جلسه کرد.
- **وابستگی:** در پنجرهٔ درس، بخش «وابستگی» می‌گوید این درس بعد از کدام درس شروع شود: بعد از پایان خواندن آن (پیش‌فرض) یا پایان مرورهایش. درس از روز بعد شروع می‌شود و روی کارتش «🔒 منتظر…» می‌آید. جابه‌جایی دستی در تقویم از وابستگی رد می‌شود و پیش‌نیاز غیرفعال نادیده گرفته می‌شود.
- **بایگانی:** درس تمام‌شده با دکمهٔ 🗄 از فهرست پنهان می‌شود و در تب «بایگانی» می‌ماند. سابقه‌اش حفظ می‌شود.
- **افزودن درس:** دکمهٔ «+ درس». تعداد و زمان جلسه‌ها، دسته، سرعت و منبع را مشخص کنید. برای PDF کل بازهٔ صفحه را بدهید تا خودکار بین جلسه‌ها تقسیم شود.
- **کار روتین:** دکمهٔ «+ کار روتین». تاریخ شروع و در صورت نیاز روزهای هفته را انتخاب کنید.
- **صف:** درس‌ها را از دستگیرهٔ ⋮⋮ بکشید. کارت همراه ماوس حرکت می‌کند و بقیه کنار می‌روند. جای درس در صف همان اولویت آن است؛ تاریخ‌های پایان و تقویم فوراً، با انیمیشن، عوض می‌شوند. اگر جلسه‌ای از آن درس قبلاً در تقویم دستی جابه‌جا شده بود (📌)، با کشیدن درس در صف آن جابه‌جایی برداشته می‌شود تا درس طبق اولویت تازه چیده شود. دکمهٔ «برگشت به چینش خودکار» روی کارت درس هم همین کار را می‌کند.
- **دسته‌ها:** هر دسته یک تب بالای فهرست است. «+» کنار آخرین تب = دستهٔ تازه. دوبار کلیک روی تب = تغییر نام. × روی تب (با بردن ماوس) = حذف. تب‌ها را هم می‌شود کشید و جابه‌جا کرد.
- **نوع کار تازه:** دکمهٔ «+» کنار «+ کار روتین». نام (مثلاً «پروژه»)، رفتار (مثل درس با مرور، یا مثل روتین بدون مرور) و رنگ را انتخاب کنید. بعد دکمهٔ «+ پروژه» کنار بقیه می‌آید. نام و رنگ از تنظیمات قابل تغییر است.
- **فعال/غیرفعال:** تیک کنار هر درس. درس غیرفعال در فهرست می‌ماند ولی وارد برنامه نمی‌شود.
- **ویرایش، تغییر تقسیم‌بندی، برگرداندن به خوانده‌نشده و حذف:** دکمهٔ ✎ روی هر درس.

## استفاده: تقویم

- **نمای روزانه، هفتگی و ماهانه:** دکمه‌های بالای تقویم. نمای روزانه یک روز را بزرگ نشان می‌دهد و با فلش‌ها روزبه‌روز جلو و عقب می‌رود. در نمای ماهانه روی هر روز کلیک کنید تا هفتهٔ همان روز کامل باز شود. روزهای آینده «پیش‌بینی» هستند و با هر تغییر از نو چیده می‌شوند.
- **رنگ‌ها:** هر کارت با رنگ نوعش پر می‌شود: پیش‌فرض خواندن قرمز، مرور آبی، روتین زرد (قابل تغییر در تنظیمات). نوع‌های ساخت شما رنگ خودشان را دارند. 📌 یعنی کار دستی جابه‌جا شده است.
- **انیمیشن:** هر تغییری که برنامه را از نو می‌چیند، کارها را با حرکت نرم به جای تازه‌شان می‌برد، تا ببینید چه چیزی کجا رفت.
- **جابه‌جایی:** کار را به روز دیگری بکشید (یک کپی از کار همراه ماوس می‌آید و روز مقصد رنگی می‌شود)، یا روی آن کلیک کنید و «به تعویق انداختن به فردا» یا «انتقال به…» را بزنید. کار زودتر از روز انتخابی نمی‌آید و اگر آن روز انجام نشود، جلوتر می‌رود. مرورهای بعدی‌اش هم با آن جابه‌جا می‌شوند.
- **مرورها:** فقط مرور بعدی هر جلسه جابه‌جا می‌شود. برای جلسه‌ای که هنوز خوانده نشده، خواندنش را جابه‌جا کنید.
- **زمان مرور یک جلسه:** از منوی روی کار. روی همهٔ مرورهای همان جلسه اثر دارد.
- **روزها:** روی سرِ هر روز کلیک کنید تا سقف آن روز را عوض کنید، تعطیلش کنید، کاری از روزهای بعد را به آن جلو بیاورید، یا درس و کار روتین جدیدی از همان روز اضافه کنید.
- **پهنای دو ستون:** جداکنندهٔ بین منابع درسی و برنامه را به چپ و راست بکشید (یا روی آن کلیک کنید و کلیدهای جهت چپ و راست را بزنید). دوبار کلیک روی آن اندازه را به حالت پیش‌فرض برمی‌گرداند. اندازه در همین مرورگر به خاطر سپرده می‌شود.
- **تعطیلی چندروزه:** روی سرِ روز شروع کلیک کنید، تاریخ پایان را بدهید و «تعطیل کردن بازه» را بزنید. «برداشتن تعطیلی بازه» آن را برمی‌دارد.
- **یادداشت جلسه:** در منوی هر کار یک کادر یادداشت هست. همان یادداشت موقع مرور هم دیده می‌شود، 📝 روی کار می‌آید و در خروجی گوشی هم هست.
- **پررنگ کردن روزهای یک درس:** روی نام درس در فهرست منابع کلیک کنید.
- **برگرداندن و بازگرداندن:** «↶ برگرداندن» تا ۲۰ تغییر آخر را یکی‌یکی برمی‌گرداند و «↷ بازگرداندن» دوباره جلو می‌رود. عدد کنار هر دکمه می‌گوید چند مرحله می‌شود عقب یا جلو رفت. با یک تغییر تازه، مرحله‌های «بازگرداندن» پاک می‌شوند. این فهرست با بستن برنامه پاک می‌شود.
- تقویم گزینهٔ حذف ندارد. برای بیرون بردن موقت درس از تقویم، تیک فعال آن را بردارید.

## استفاده: ثبت کارهای انجام‌شده

- **تیک سریع:** روی کارهای امروز یک چک‌باکس هست. با زدنش کار با تاریخ امروز ثبت می‌شود.
- **منوی کار:** «✓ انجام شد»، برای مرور «↺ نیاز به مرور بیشتر» (جلسه به جعبهٔ ۱ برمی‌گردد)، و برای خواندن «فقط بخشی خواندم» با تعداد دقیقه. بقیهٔ جلسهٔ نیمه‌خوانده از فردا چیده می‌شود.
- **زودتر از برنامه:** کار روزهای بعد را هم می‌شود از منوی خودش تیک زد. با تاریخ امروز ثبت می‌شود.
- کارهای انجام‌شده با ✓ در همان روز تقویم می‌مانند و از سقف امروز کم می‌شوند.
- **انجام نشده:** روی کار تیک‌خورده کلیک کنید و «↩ انجام نشده» را بزنید. جلسه به وضعیت قبل از همان تیک برمی‌گردد و کار دوباره وارد برنامه می‌شود. این کار برای تیک‌های روزهای قبل هم هست. چون هر تیک روی تیک قبلی همان جلسه سوار است، فقط آخرین تیک هر جلسه برمی‌گردد؛ برای تیک قدیمی‌تر، اول تیک‌های بعدی همان جلسه را برگردانید.
- **حجم کار منتظر:** پایین فهرست منابع. جمع خواندن و مرور باقی‌مانده، تاریخ پایان همه‌چیز، و میانگین روزانهٔ ۳۰ روز آینده را نشان می‌دهد.
- **تاریخ هدف:** برای درسی که هدف دارد، جداگانه نشان داده می‌شود که پایان خواندن و پایان مرور چند روز زودتر یا دیرتر از هدف است.

## استفاده: خروجی و اشتراک‌گذاری

- **ساختن خروجی:** دکمهٔ «⇪ خروجی» بالای تقویم، یا «خروجی این روز» در منوی سرِ هر روز. روز، هفته یا ماه را انتخاب کنید.
- **محتوا:** خروجی روزانه به‌طور پیش‌فرض خود مطالب را هم دارد: صفحه‌های همان جلسه از PDF به شکل عکس، و متن همان بخش از نوت Markdown. خروجی هفتگی و ماهانه به‌طور پیش‌فرض فقط فهرست کارهاست، با گزینهٔ «همراه با مطالب».
- لینک‌ها به شکل متن می‌آیند. ویدیوهای محلی فقط با نام و آدرس می‌آیند، چون حجمشان زیاد است.
- **فایل:** یک فایل HTML مستقل است و فونت و عکس‌ها داخل خودش‌اند. روی گوشی بدون اینترنت باز می‌شود. ذخیره در `Documents/Dibacheh Exports` (قابل تغییر با تنظیم `export_folder`).
- **اشتراک‌گذاری:** اگر مرورگر پنجرهٔ Share را برای فایل پشتیبانی کند (مثلاً Safari)، دکمهٔ «اشتراک‌گذاری…» آن را باز می‌کند. وگرنه «نمایش در Finder» فایل را انتخاب‌شده نشان می‌دهد تا آن را به تلگرام بکشید.
- تیک‌های داخل فایل خروجی فقط برای خودتان است و به Mac برنمی‌گردد.

## استفاده: گزارش

دکمهٔ «📊 گزارش» بالای صفحه سه سربرگ دارد: **هفتگی** (خلاصهٔ هفته و نمودار ۱۲ هفتهٔ اخیر)، **ماهانه** (خلاصهٔ ماه شمسی و نمودار ۱۲ ماه اخیر) و **کلی** (جمع همهٔ سابقه، نقشهٔ فعالیت یک سال اخیر و پیشرفت هر دسته). با فلش‌ها به هفته یا ماه قبل می‌روید. «⇪ خروجی گزارش» همان گزارش را به شکل فایل HTML در پوشهٔ خروجی می‌سازد.

## استفاده: تنظیمات

دکمهٔ «⚙ تنظیمات» بالای صفحه:

- **برنامه‌ریزی:** سقف پیش‌فرض روز، مقدار مجاز بیشتر شدن از سقف (پیش‌فرض ۳۰ دقیقه)، سقف و تعطیلی هر روز هفته، ساعت شروع روز، سقف زمان مرور (پیش‌فرض خاموش).
- **زمان مرور:** اسلایدر درصد. زیرش با یک مثال نوشته می‌شود که هر مرور چند دقیقه می‌شود و در بلندمدت چقدر از روز برای مطلب جدید می‌ماند.
- **فاصله‌های لایتنر:** چند گزینهٔ آماده هست (استاندارد، فشرده، لایتنر کلاسیک، بلندمدت، سبک). روی نمودار، هر نقطه یک مرور است. نقطه را به چپ و راست بکشید. «+ یک مرور دیگر» نقطهٔ تازه اضافه می‌کند و «− حذف یک مرور» آخرین مرور را برمی‌دارد. برای حذف یک مرور خاص، × کنارش در فهرست زیر نمودار را بزنید (یا روی نقطه‌اش دوبار کلیک کنید). با + و − در انتهای نمودار، طول آن یک ماه یک ماه عوض می‌شود. تغییر فاصله‌ها تاریخ همهٔ مرورها را دوباره حساب می‌کند.
- **رنگ‌بندی برنامه:** «بر اساس نوع کار» (خواندن، مرور، روتین) یا «بر اساس منبع» (هر درس با رنگ خودش و مرورها با خط‌چین). رنگ هر منبع از مربع رنگی روی کارت درس، پنجرهٔ ویرایش درس، یا همین‌جا عوض می‌شود. نام و رنگ نوع‌های ساخت شما هم اینجاست.
- **درس جدید:** زمان جلسه، سرعت و دستهٔ پیش‌فرض.
- **ظاهر:** حالت روشن و تیره، فونت و اندازهٔ فونت. Vazirmatn و هفت فونت فارسی رایگان و متن‌باز (صمیم، شبنم، ساحل، استعداد، پرستو، گندم، تنها) داخل برنامه‌اند و مجوز هرکدام کنار فایلش در `static/vendor/fonts` است؛ همه در کادر باز شوی «فونت» هستند. «+ افزودن فایل فونت…» یک فایل ttf، otf، woff یا woff2 را می‌گیرد و کپی‌اش را در `data/fonts` نگه می‌دارد؛ همان فونت در خروجی گوشی هم استفاده می‌شود.
- **فایل‌ها:** والت Obsidian، پوشهٔ خروجی، پوشه و تعداد backup.

مقدارهای نامعتبر (مثلاً فاصلهٔ لایتنر صفر) پذیرفته نمی‌شوند و هیچ تنظیمی نیمه‌کاره ذخیره نمی‌شود.

## تغییر دادن کد

هر فایل یک کار مشخص دارد و بالای هر فایل توضیح داده شده که چه می‌کند. چند راهنمای سریع:

| می‌خواهید… | کجا |
|---|---|
| قانون چینش برنامه را عوض کنید | `scheduler.py`، تابع `build_plan`. ترتیب کار هر روز بالای فایل نوشته شده است |
| قانون جعبه‌های لایتنر را عوض کنید | `leitner.py` |
| مقدار پیش‌فرض یک تنظیم را عوض کنید | `DEFAULT_SETTINGS` در `database.py` |
| یک ستون به دیتابیس اضافه کنید | یک مورد تازه به انتهای `MIGRATIONS` در `database.py` |
| رنگ‌ها را عوض کنید | بالای `static/style.css` (بخش `:root`، و `[data-theme="dark"]` برای حالت تیره) |
| صفحهٔ منابع درسی را عوض کنید | `static/js/sources.js` و `templates/index.html` |
| پنجرهٔ درس یا تنظیمات را عوض کنید | `static/js/item-dialog.js` یا `static/js/settings.js` |
| تقویم را عوض کنید | `static/js/calendar.js` |
| مسیر تازهٔ سرور اضافه کنید | `routes/` برای مسیر و `services/` برای منطق |
| شکل خروجی HTML را عوض کنید | `exporter.py` (قالب صفحه، `PAGE`، انتهای فایل است) |

**روش امن تغییر:**

1. قبل از تغییر، برنامه را با دیتابیس جدا امتحان کنید (دستور `DIBACHEH_DB=...` در بخش «اجرا»).
2. بعد از تغییر، تست‌ها را اجرا کنید تا مطمئن شوید چیزی خراب نشده.
3. اگر چیزی خراب شد، Git همهٔ نسخه‌های قبلی را دارد. `git status` می‌گوید چه فایل‌هایی عوض شده‌اند و `git diff` دقیقاً چه چیزی.

**به‌روز کردن کتابخانه‌ها** (اینترنت لازم دارد): نسخه‌ها در `requirements.txt` ثابت شده‌اند. بعد از تغییر آن فایل، دستور نصب را دوباره اجرا کنید. Dependabot هر هفته نسخه‌های تازه را در GitHub به شکل pull request پیشنهاد می‌دهد. تست‌ها روی آن اجرا می‌شوند و تا خودتان تأیید نکنید چیزی عوض نمی‌شود.

**گزارش خطا:** اگر برنامه درست کار نکرد، در تنظیمات دکمهٔ «نمایش گزارش خطا» را بزنید. گزارش روی همین کامپیوتر می‌ماند و جایی فرستاده نمی‌شود.

## داده‌ها و backup

- همهٔ داده‌های برنامه در فایل `data/dibacheh.sqlite3` است. خود منابع (نوت، PDF) سر جای خودشان می‌مانند.
- هر روز، اولین باری که برنامه باز می‌شود، یک کپی در `data/backups/` ساخته می‌شود، با نامی مثل `dibacheh-2026-11-05.sqlite3`. سالم بودن هر کپی بررسی می‌شود و اگر مشکلی داشت، بالای صفحه هشدار می‌آید.
- ۳۰ نسخهٔ آخر نگه داشته می‌شود و نسخه‌های قدیمی‌تر خودکار پاک می‌شوند. فایل‌های دیگرِ آن پوشه دست نمی‌خورند.
- پوشهٔ `data/` وارد Git و GitHub نمی‌شود.

**برگرداندن یک backup:** در تنظیمات، بخش «برگرداندن backup»، نسخهٔ دلخواه را انتخاب کنید. قبلش یک کپی از وضعیت فعلی گرفته می‌شود و با «↶ برگرداندن» هم برمی‌گردد.

**انتقال به Mac دیگر:** در تنظیمات، «ساختن فایل داده‌ها» یک فایل zip با همهٔ داده‌ها و فونت‌های اضافه‌شده می‌سازد و «ورود از فایل…» آن را روی Mac دیگر وارد می‌کند. فایل‌های منبع جدا منتقل می‌شوند و بعد از انتقال، مسیر والت را در تنظیمات اصلاح کنید.

**برگرداندن دستی:**

1. برنامه را ببندید (پنجرهٔ Terminal آن را ببندید).
2. فایل `data/dibacheh.sqlite3` را برای احتیاط به جای دیگری منتقل کنید.
3. فایل backup دلخواه را در `data/` کپی کنید و نامش را `dibacheh.sqlite3` بگذارید.
4. برنامه را دوباره باز کنید.

**اگر ساختار جدول‌ها را تغییر دادید:** یک مورد جدید به انتهای فهرست `MIGRATIONS` در `database.py` اضافه کنید و موارد قبلی را عوض نکنید. برنامه موقع باز شدن فقط migrationهای تازه را اجرا می‌کند و داده‌ها می‌مانند.

## ساختن نسخهٔ نصبی

نسخه‌های همهٔ سیستم‌ها روی ماشین‌های GitHub ساخته می‌شوند (`.github/workflows/release.yml`). برای انتشار نسخهٔ تازه، عدد فایل `VERSION` را عوض کنید، commit کنید و یک تگ بفرستید:

```bash
git tag v1.2.0 && git push origin v1.2.0
```

تست‌ها روی هر چهار سیستم اجرا می‌شوند، نسخهٔ ساخته‌شده واقعاً اجرا و امتحان می‌شود (`tools/smoke_test.py`) و فایل‌ها به یک Release پیش‌نویس اضافه می‌شوند. بعد آن را در GitHub منتشر کنید.

ساختن روی همین کامپیوتر: `zsh tools/build_release.sh` روی Mac و `python tools/build_release.py` روی ویندوز و لینوکس. خروجی در `build/release` است.
